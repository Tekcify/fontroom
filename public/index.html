How it works

Google Fonts shows a sample sentence. Fontroom shows the font where it will actually live.

  1. 1

    Search any Google Font

    Filter by style, type the exact name of any family, or drop in your own font file. It never leaves your device.

  2. 2

    Try it on a real page

    Hover a font to see it on a website and a phone app at actual size. Click to keep it.

  3. 3

    Copy the code

    Get the setup for your stack with only the weights you picked.
